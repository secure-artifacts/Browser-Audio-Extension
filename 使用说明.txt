浏览器拉线助手 1.2.1（回声处理修复）

需要支持 remote-only 的桌面 Chromium 浏览器，最低版本 151。
用户已反馈本次修复后的实际通话正常；其他设备及多通话数量仍需按实际环境验证。

安装后默认开启，不需要再按开关。不会自动刷新网页或中断通话。

【安装】
1. 如果拿到的是 ZIP，先完整解压。不要在压缩包内部安装。
2. 谷歌 / 谷歌 Beta：地址栏输入 chrome://extensions
   微软 Edge：地址栏输入 edge://extensions
   Brave：地址栏输入 brave://extensions
3. 打开「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 manifest.json 的 Browser-Audio-Extension 文件夹。
5. 安装后刷新通话网页（未保存的文字先保存），再重新发起通话。
6. 如需显示开关，点击浏览器右上角拼图图标，把「浏览器拉线助手」固定到工具栏。

【如何测试，避免被原来的 EXE 启动参数干扰】
1. 先保存工作并结束通话。彻底退出所有相关浏览器进程。
2. 用原来的普通浏览器快捷方式打开，不要通过「拉线启动器」EXE 打开。
   如果设置过启动器开机启动，请避免它先启动浏览器；不要为测试删除你的设置。
3. 检查 chrome://version（Edge / Brave 改用自己的前缀）的「命令行」：
   不应包含 ChromeWideEchoCancellation 或 WebRtcAllowInputVolumeAdjustment 禁用参数。
   若原来手动更改过音频相关 flags，也要先记录原值，再恢复默认并重启，以免混淆结果。
4. 安装此插件，刷新网页；在网站通话设置中选择 VoiceMeeter 的虚拟输出或「立体声混音」。
   插件不会替你切换麦克风设备，也不会自行捕获电脑播放声音。
5. 建议双方戴耳机，用同一段音乐比较：
   A. 插件开启 → 刷新 → 重新通话，让对方听。
   B. 插件关闭 → 刷新 → 重新通话，播放同一段音乐。
   请记录浏览器完整版本、网站、所选麦克风，以及「能听到 / 被压低 / 完全听不到」。
6. 不要只凭 ON 标志判断成功。ON 仅表示开关开启。
   在通话网页上点击插件图标，面板会每两秒检测一次当前页（包含可访问的内嵌页面）。
   「远端回声抑制已启用」表示原生设置回报 echoCancellation="remote-only"，
   autoGainControl=false、noiseSuppression=false；不证明通话已无回音或对方已收到声音。
   对比时不要同时启用其他会修改麦克风设置的插件，两个通话页都要刷新后重建通话。

【状态提示】
已就绪·等待使用麦克风：脚本已加载，但网页还没有正在采集的麦克风音轨。
需要刷新网页：当前页面没加载新版本脚本；保存内容后刷新并重新通话。
关闭待刷新：开关已经关闭，但旧页面中还有已注入的处理；刷新后才完全恢复。
远端回声抑制已启用：已检查的音轨回报 remote-only，自动增益与降噪回报关闭。
音频设置未符合要求：至少一个被观察的音轨不符合上述目标，暂不能认为已应用。
采集中·无法完整确认：浏览器没有完整回报设置，不伪造为成功。
远端回声抑制已设置·有音轨暂停：音轨被静音、禁用或暂时没有数据，不代表对方正在听到声音。
检测到音频请求失败：下面会提示权限、设备缺失、占用、不兼容等可能原因及处理方法。
此页面无法检测：浏览器内部页面、商店等受保护页面不支持，或插件没有该页访问权限。
诊断在页面运行环境中读取，不是防篡改的安全证明。没有捕获到的音轨无法确认。

【开关与范围】
默认开启；开关记住在当前浏览器个人资料中，重启后保留。
开启、关闭、更新、禁用或移除插件后，原先打开的网页都应刷新一次。
切换不会立即改变已经进行的通话，不会恢复已注入页面里的旧函数。
Chrome、Chrome Beta、Edge、Brave 以及各个人资料需要分别安装。
普通 HTTP/HTTPS 网页和允许注入的内嵌页面都会尝试应用。
浏览器内部设置页、扩展商店受保护页面、其他扩展页面等不支持。
无痕模式默认不启用；需要用户在扩展详情中自行允许。
浏览器的网站访问权限如果被限制为「点击时」或「指定网站」，会限制插件生效范围。

【它具体做什么】
在页面最早加载阶段包装 getUserMedia，并对麦克风请求尝试强制：
echoCancellation = "remote-only"，autoGainControl = false，noiseSuppression = false。
同时处理传统麦克风接口、已采集麦克风音轨的 applyConstraints 与克隆音轨。
0.2.0 还跟踪纯麦克风 MediaStream 的整体克隆，保留继承而来的设备/摄像头约束。
不改摄像头约束，不改屏幕共享接口，不伪造音轨设置结果。
若浏览器不支持 remote-only 或设备无法满足要求，麦克风申请可能失败。
插件会报告错误，不会自动退回关闭回声抑制；关闭插件并刷新即可恢复网页默认。
网站独立的音频算法、受限页面、覆盖接口或没有经过这些接口的声音仍可能不受影响。

这是网页层的音频兼容处理，不会修改 chrome://flags、浏览器启动参数、驱动或 Windows 音频设置。
不能宣称等价于禁用 Chrome-wide echo cancellation 或 Allow WebRTC to adjust the input volume。
不能保证所有网站、版本或设备有效；不能保证接收方收到双声道。
关闭降噪可能增加环境噪音；远端回声抑制不能保证完全无回音或啸叫。
请先用低音量复测。插件没有实现对每个标签页独立的音频分流或混音减自身算法。

【隐私】
所需权限：在 HTTP/HTTPS 网页中运行本地脚本，以及保存一个开关值。
面板打开时读取当前标签页的音轨设置摘要（开关布尔值、音轨数量、错误类型）；
不读取或保存设备名称/设备 ID，不保存诊断日志。关闭面板后停止轮询。
由于支持全网站，浏览器会提示网站数据访问权限，请按你的意愿决定是否授权。
本插件不读取聊天、密码、Cookie、浏览历史，不录音，不上传数据，没有远程代码和外部服务。
不使用 GitHub Token；包内不含任何账号密钥。

【卸载】
在扩展管理页点击「移除」，随后刷新通话网页即可。
安装时选择的文件夹需要保留，不要在使用中删除或移动。

本地测试结果另见测试记录。Facebook 等真实通话的效果需要用户实测。

【升级】
已经从同一个文件夹加载旧版：保存内容、结束通话，然后到扩展管理页点击本插件的
「重新加载」圆形箭头。再刷新两个通话网页并重建通话。面板底部应显示 v1.2.1。
无需移除重装；原先的全局开关状态会保留。不要同时启用两份不同路径的旧/新插件。
如果拿到 ZIP 更新包：先关闭相关通话，把解压后的插件文件覆盖到原安装文件夹，
再执行上面的「重新加载」步骤。保留旧文件备份，便于需要时恢复。
目前仍为本地手动升级，未上架商店，没有后台联网检查和自动更新。
商店安装及自动更新需要另行确定发布渠道、准备上架资料并完成审核，尚未执行。
